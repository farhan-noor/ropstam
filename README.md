# Ropstam Services Plugin - Coding Challenge
This coding challange ads a services post type in WordPress that can be managed from the WordPress admin panel. Most recently updated 3 services are shown on the front end using a shortcode. 
## Instructions
Download zip package.
Install this package from the plugins section WordPress admin panel.
Add few services from the Services section in WordPress admin panel. 
Edit or create a new page in WordPress admin panel Where you want to list the available services.
In the page block editor, write [services] shortcode in the WordPress Code block.
