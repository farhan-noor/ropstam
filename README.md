# Ropstam Services Plugin - Coding Challenge
This coding challange ads a services post type in WordPress that can be managed from the WordPress admin panel. Most recently updated 3 services are shown on the front end using a shortcode. 
## Instructions
1. Download zip package.
2. Install this package from the plugins section in WordPress admin panel.
3. Add few services from the Services section in WordPress admin panel. 
4. Edit or create a new page in WordPress admin panel where you want to list the available services.
5. In the page block editor, write [services] shortcode in the WordPress Code block.
